# Integration rules

Read README.md and docs/API.md. Only StateMachineManagerRoblox.lua is required; StateMachineGroup.lua is optional. Use compile once when many entities share a graph. One machine per logical entity. Explicit legal edges; guards return exactly true. Send maps events to edges; Step consumes caller-supplied time, at most one committed transition. All callbacks synchronous; no yielding or mutation reentry. Update may return target and payload. Exit/Enter/OnChanged run after commit in that order; true + NOTIFICATION_FAILED means already committed. Initial/destroy do not invoke hooks. Use Token/TransitionIfCurrent or SendIfCurrent for stale async completion; check IsCurrent before other side effects. The caller owns scheduling, context, connections, and cleanup. Group membership is not ownership. Handle group summary issues individually. No claims of network authority, exact timing, formal proof or Roblox capacity from CLI tests.
